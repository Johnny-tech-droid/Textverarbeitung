# MiniText

A small text editor built with **Java Swing** (learning project from my Java course): new, open, save and save as, print, a toolbar, a context menu and basic formatting.

## Requirements

- JDK 17 or newer

## Run

Open the folder in IntelliJ IDEA (`Textverarbeitung.iml`) and start `de.fernschulen.minitext.MiniTextView`.
